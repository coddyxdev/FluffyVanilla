# Fluffy Vanilla Bot

Discord-бот сообщества Fluffy Vanilla на Python и `discord.py`: заявки в whitelist, тикеты, модерация, автомодерация, временные голосовые каналы, Minecraft-статистика, аудит и предложения игроков.

## Возможности

- Заявки в whitelist с проверкой ника, решениями администрации и повторной выдачей на Minecraft-сервер.
- Обычные и технические тикеты, назначение сотрудника, оценки и автоархивация.
- Модерация, предупреждения, временные наказания, автомод и анти-рейд.
- Временные голосовые каналы с собственной панелью управления.
- Статистика Minecraft, профили игроков и достижения.
- Розыгрыши с требованиями по ролям, автоматическим завершением и перевыбором.
- Версионируемые миграции SQLite, резервные копии и структурированный аудит.
- Диагностика `/health` и проверка настроек `/setup check`.

## Требования

- Python 3.11 или новее.
- Discord-приложение с ботом.
- В Developer Portal должны быть включены **Server Members Intent** и **Message Content Intent**.
- Для статистики, whitelist и безопасной привязки нужен совместимый Minecraft HTTP-плагин.

## Установка

```bat
cd C:\Users\coddy\Desktop\FluffyVanillaBot
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install -U pip
pip install -r requirements.txt
copy .env.example .env
```

Заполни `.env`, затем запусти:

```bat
start.bat
```

После первого запуска:

1. Настрой каналы и роли командами `/setup ...`.
2. Выполни `/setup check`.
3. Выполни `/health`.
4. Размести панели whitelist и тикетов.

## Основные команды

- `/health` — состояние Discord, SQLite, WAL, прав и Minecraft API.
- `/audit recent`, `/audit user` — структурированный журнал действий.
- `/giveaway create`, `/giveaway end`, `/giveaway cancel`, `/giveaway reroll`, `/giveaway list`.
- `/backup now`, `/backup list`.

## База данных

Миграции применяются автоматически и записываются в `schema_migrations`. При ошибке миграция откатывается, запуск прекращается, а причина попадает в лог. Не изменяй номера уже выпущенных миграций — добавляй новую версию.

Перед обновлением проекта рекомендуется выполнить `/backup now`.

## Безопасность

- Никогда не публикуй `.env`, токен бота и API-ключ Minecraft.
- `.env`, SQLite/WAL, логи, бэкапы, кэш и виртуальное окружение исключены через `.gitignore`.
- Не отправляй содержимое `.env` в тикеты или команды диагностики.
- Держи роль бота выше ролей, которыми он управляет.
